# Appendix p 15: Data availability and supplementary tables

**Supplementary Table S1.** Complete pLIN assignment table for all 6,998 training plasmids. Columns: plasmid_id, inc_type, length_bp, pLIN, bin_A through bin_F.

**Supplementary Table S2.** Integrated pLIN + AMRFinderPlus table with AMR, virulence, and stress gene annotations for all 6,998 plasmids. Columns: plasmid_id, inc_type, length_bp, pLIN, bin_A–F, n_amr_genes, n_vir_genes, n_stress_genes, n_total_hits, amr_genes, vir_genes, stress_genes, amr_classes, amr_subclasses.

**Supplementary Table S3.** pLIN lineage AMR summary with characteristic resistance profiles for all 2,454 strain-level lineages. Columns: pLIN, n_plasmids, mean_amr, total_amr, inc_types, top_amr_genes.

**Supplementary Table S4.** Full reference database pLIN assignment for 79,305 plasmids. Columns: plasmid_id, inc_type, inc_confidence, length_bp, pLIN, bin_A through bin_F, source (training/reference), inc_secondary, is_novel.

**Supplementary Table S5.** Clinically critical resistance gene detections. Columns: plasmid_id, pLIN, inc_type, gene_symbol, gene_category (carbapenemase/ESBL/mcr/PMQR), drug_class, drug_subclass.

All supplementary data available at https://github.com/xavierbasilbritto-hub/pLIN-plasmid-classification under GPL-3.0 licence. All plasmid sequences obtained from NCBI RefSeq; accession numbers listed in Supplementary Table S1 and S4.
